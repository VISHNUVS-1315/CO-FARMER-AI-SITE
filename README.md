## Download the App
The Android APK is published as a **GitHub Release** (source code stays private):

1. Open the repo **Releases** tab
2. Download **CoFarmerAI_v1.0.apk** (latest release)

Direct link: `https://github.com/VISHNUVS-1315/CO-FARMER-AI-SITE/releases/latest/download/CoFarmerAI_v1.0.apk`

The `release/` folder in this repo holds a local copy of the current APK — upload it when creating a new release.

## Files
- `index.html` — the portfolio/download page
- `assets/` — site styles, scripts and module screenshots
- `release/` — APK build for publishing
